1. Aim

To develop an automated LLM evaluation pipeline that benchmarks a local open-source language model (Llama 3.2 via Ollama) against a curated 30-question golden question set, computes keyword-based coverage scores, evaluates answers against pass criteria (PASS ≥ 60% vs. REVIEW), automatically exports evaluation records to baseline_results.csv, and tags the experiment as Release v0.1.

2. Software Used

Windows 11, Python 3.14, Visual Studio Code, Windows PowerShell, Ollama local runtime (v0.40.16), Llama 3.2 (3B) open-weights LLM, and the Python requests package.

3. Procedure

  1. Open Windows PowerShell and check the installed Ollama runtime version using ollama --version.
  2. Download the compact open-source model Llama 3.2 locally using ollama pull llama3.2.
  3. Open Visual Studio Code, navigate to the project directory, and create the WEEK-6 folder.
  4. Inside WEEK-6, create golden_set.json, requirements.txt, and main.py.
  5. Populate golden_set.json with 30 curated questions covering GenAI concepts (tokenization, token economics, decoding strategies, embeddings, and positional encodings) with expected answers, evaluation keywords, and source citations.
  6. Specify requests in requirements.txt and install dependencies using pip install -r requirements.txt.
  7. Implement main.py to submit questions to http://localhost:11434/api/generate with zero temperature (greedy decoding), perform case-insensitive keyword scoring, determine PASS/REVIEW status, log question results, and export the dataset to baseline_results.csv.
  8. Execute the script using python main.py, inspect the evaluation summary, and verify the generated CSV output for Release v0.1.

5. Program Logic

Load 30 benchmark questions from golden_set.json → query Ollama REST API (/api/generate) with model="llama3.2" and temperature=0 → receive response string → check presence of required keywords → compute keyword coverage score percentage (matched / total) × 100 → assign status (PASS for ≥ 60%, else REVIEW) → write records to baseline_results.csv → output summary statistics and tag Release v0.1.

6. Result

# PRACTICAL > WEEK-6 > main.py import json, csv, requests from datetime import datetime OLLAMA_URL = "http://localhost:11434/api/generate" MODEL_NAME = "llama3.2" INPUT_FILE = "golden_set.json" OUTPUT_FILE = "baseline_results.csv" def get_llm_answer(question): payload = { "model": MODEL_NAME, "prompt": question, "stream": False, "options": {"temperature": 0} } response = requests.post(OLLAMA_URL, json=payload, timeout=120) response.raise_for_status() return response.json().get("response", "").strip() def calculate_score(answer, expected_keywords): answer = answer.lower() matched = [k for k in expected_keywords if k.lower() in answer] missing = [k for k in expected_keywords if k.lower() not in answer] score = (len(matched) / len(expected_keywords)) * 100 if expected_keywords else 0 return round(score, 2), matched, missing
